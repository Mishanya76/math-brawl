# Математический Браул 🎮

Лендинг-игра для тренировки математики во 2 классе. Решай примеры, зарабатывай монеты и собирай команду бойцов в стиле Brawl Stars.

## Режимы
- **Двузначные числа** — сложение и вычитание до 100
- **Трёхзначные числа** — сложение и вычитание до 1000
- **Таблица умножения** — примеры от 2 × 2 до 9 × 9

## Что умеет игра
- **Разбор ошибок** — при неверном ответе показывается правильное решение шаг за шагом (сложение — разложением, вычитание — с заёмом, умножение — как сумма одинаковых слагаемых)
- **Ввод ответа** — можно выбрать вариант или ввести число с клавиатуры; варианты можно скрыть в настройках для тренировки
- **Монеты и серии** — 5 / 8 / 6 монет за верный ответ (по режимам), бонус за серию и +25 за идеальный раунд из 10 вопросов
- **12 бойцов** четырёх редкостей с множителем монет ×1 / ×1.2 / ×1.5 / ×2
- **Настройки** — звук, громкость, вибрация, показ вариантов ответов
- **PWA** — игру можно установить на телефон/планшет и запускать офлайн
- **Сохранение прогресса** — монеты, бойцы и настройки хранятся в localStorage

## Запуск
Открой `index.html` в браузере — сборка и сервер не нужны. Для установки как приложения используй «Установить»/«На экран домой» в браузере (требуется открытие по HTTP/HTTPS, например через GitHub Pages).

## Файлы
- `index.html` — разметка лендинга
- `styles.css` — оформление и анимации
- `script.js` — логика игры, разбор ошибок, бойцы, монеты, сохранение
- `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png` — PWA

## Идеи для развития
- Адаптивная сложность и тренировка слабых мест
- Достижения, ежедневные задания, сундуки
- Статистика и профили игроков
- Новые режимы (деление, сравнение чисел)
